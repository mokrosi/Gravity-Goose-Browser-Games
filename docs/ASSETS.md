# ASSETS

## Visuals
All visuals are generated programmatically at runtime using `Phaser.GameObjects.Graphics`.
This guarantees a zero-asset footprint, perfect scaling, and instant load times.

- `slime`: 24x20 rounded green rectangle.
- `bot_intern`: 20x24 grey rectangle with a blue visor.
- `bot_manager`: 28x32 bulky grey rectangle with a red tie.
- `tile_fan`: Transparent blue rectangle.
- `tile_bounce`: Orange pad.

## Audio
All sounds are generated using `zzfx.js` (Frank Force, 2019).
- `sfx.jump()`: Squishy bop.
- `sfx.dash()`: Wet splash.
- `sfx.hit()`: Heavy thud.
- `sfx.stomp()`: Bass-heavy squash.
