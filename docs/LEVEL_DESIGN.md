# LEVEL DESIGN

All levels follow the 4-step philosophy: Introduce, Develop, Twist, Discard.

- **Floor 1: Cubicle Hell**: Introduces basic platforming and destructible desks/water coolers.
- **Floor 2: The Server Room**: Introduces vertical drafts (Fans). Players must use fans to cross large horizontal gaps.
- **Floor 3: Bounce Dept**: Introduces Bounce Pads. Chaining dashes into bounce pads creates extreme verticality.
- **Floor 4: The Vents**: Combines Fans and Bounce Pads into high-speed momentum puzzles.
- **Floor 5: The Boardroom**: Enemy density maxed out. Heavily populated with Manager Bots.
