# GAME DESIGN

## The 20-Second Rule
Every 20 seconds, the player should experience something new:
- A new mechanic (bouncers, fans).
- A funny interaction (Intern bot panicking).
- A mini-puzzle (smashing a water cooler to progress).

## Player Psychology
- **Curiosity**: Hidden rooms placed slightly out of camera bounds encourage exploration.
- **Humor**: Breaking the sterile office environment with chaotic slime creates joy.
- **Reward**: Popping enemies generates satisfying shards and sound effects.

## The Loop
Run -> Encounter obstacle -> Use momentum to smash/bypass -> See funny reaction -> Reach elevator.
